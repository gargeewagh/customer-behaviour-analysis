# Customer Shopping Behaviour Analysis

## Overview

Customer Shopping Behaviour Analysis is an end-to-end data analytics project developed to understand customer purchasing patterns, preferences, and spending habits using retail transaction data. The project leverages Python, PostgreSQL, SQL, and Power BI to transform raw data into meaningful business insights that support data-driven decision-making.

## Dataset

The dataset contains approximately 3,900 customer purchase records and includes information such as customer demographics, product categories, purchase amounts, subscription status, shipping preferences, payment methods, previous purchases, and review ratings.

## Tools & Technologies

* PostgreSQL
* SQL
* Power BI

## Project Workflow

### 1. Data Preparation & EDA

* Loaded and explored the dataset using Python.
* Performed data cleaning and preprocessing.
* Handled missing values and standardized column names.
* Conducted Exploratory Data Analysis (EDA) to identify trends and patterns.

### 2. SQL Analysis

* Imported the cleaned dataset into PostgreSQL.
* Wrote 10 business-focused SQL queries.
* Analyzed customer segments, subscription behaviour, revenue contribution, category performance, and purchasing trends.

### 3. Dashboard Development

* Built an interactive Power BI dashboard.
* Created KPI cards, revenue and sales analysis, subscription insights, and customer demographic visualizations.
* Added interactive filters for dynamic analysis.

### 4. Reporting & Presentation

* Prepared a detailed project report documenting methodology and findings.
* Created a professional presentation using Gamma to communicate key insights.
